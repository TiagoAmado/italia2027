# Itália 2027 — Roteiro Interativo

Roteiro de lua de mel pela Itália (Roma → Sorrento → Florença → Bologna → Veneza → Roma, 22/3–5/4/2027), em uma página HTML autocontida — sem build, sem dependências além de fontes do Google Fonts.

Publicado via GitHub Pages: https://tiagoamado.github.io/italia2027/

Para editar o roteiro (datas, atividades, preços, hotéis), veja o array `DAYS` em [data.js](data.js). Detalhes de arquitetura em [CLAUDE.md](CLAUDE.md).
